# Coming Soon Page

This repository contains a simple "Coming Soon" landing page with a countdown timer. It's designed to inform visitors about an upcoming product launch and display the time remaining until the release.

## Features

- Responsive design using flexbox
- Countdown timer showing days, hours, minutes, and seconds
- Automatic message update when the launch date passes

## Files

- `index.html` - main HTML page with structure and embedded JavaScript
- `style.css` - styling for the page

## Usage

1. Open `index.html` in a web browser.
2. The countdown automatically starts and updates every second.
3. Adjust the `launchDate` value in the `<script>` tag to change the target date.

## Customization

- Modify styles in `style.css` for branding or layout changes.
- Add additional elements such as email sign-up forms or social links as needed.
